미션과 비전

1928 100 Years of Care 2028 ACTS

100년의 생명존중 헤리티지, 미래 간호 100년을 여는 'ACTS 2028'

1928년 조선여자의학강습소에서 태동하여 환자 중심의 참된 인술을 실천해 온 고려대학교 의료원은 창립 100주년이 되는 2028년을 바라보며, 4대 실천 전략(ACTS)과 4대 핵심가치로 인류를 건강하고 행복하게 만드는 글로벌 선도 간호부를 지향합니다.

MISSION

"생명존중의 미래간호로 인류를 건강하고 행복하게 한다"

고려대학교 구로병원 간호부는 환자의 생명과 존엄성을 최고의 가치로 삼고, 첨단 의과학과 따뜻한 온기가 결합된 미래 간호 표준을 만들어 갑니다.

ACTS 2028 FRAMEWORK

미래 비전과 4대 핵심가치 실천 체계

A
Care 01 · Value 01

Anthropocentric

CARE VISION

환자 한 분 한 분의 삶과 존엄성을 최우선으로 여기는 인간중심 돌봄을 실천합니다.

CORE VALUE
Activeness 주도성

변화를 두려워하지 않고 솔선수범하는 자세로 최선의 간호를 주도합니다.

C
Care 02 · Value 02

Connected

CARE VISION

병원과 지역사회, 환자와 의료진을 유기적으로 잇는 연계 간호 생태계를 구축합니다.

CORE VALUE
Collaboration 협업

다학제 팀과의 원활한 소통과 상호 존중으로 최상의 시너지를 창출합니다.

T
Care 03 · Value 03

Team-based

CARE VISION

원팀(One-Team)의 결속력과 상호 신뢰를 바탕으로 안전한 팀 간호를 완성합니다.

CORE VALUE
Trust 신뢰

원칙과 표준 실무를 엄격히 준수하여 동료와 환자에게 두터운 믿음을 줍니다.

S
Care 04 · Value 04

Specialized

CARE VISION

첨단 의학 지식과 과학적 임상 연구로 고도화된 전문 간호 역량을 실현합니다.

CORE VALUE
Sincerity 진정성

따뜻한 공감과 진심 어린 태도로 환자의 아픔을 먼저 어루만집니다.

THE ACTS OF THE K-NURSE

고대구로 간호사가 실천하는 행동 규범

Anthropocentric Care(인간중심)를 위해 주도성(Activeness)을 발휘하고, Connected Care(연계간호)를 위해 협업(Collaboration)하며, Team-based Care(팀기반)를 위해 신뢰(Trust)를 쌓고, Specialized Care(전문간호)를 위해 진정성(Sincerity)을 다합니다.
